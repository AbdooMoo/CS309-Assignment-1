# Abdelrahman Mohamed's Website

A simple personal website built with HTML and CSS. It contains three linked pages.

## Pages

- `index.html`: The home page.
- `about.html`: Information about Abdelrahman and his skills.
- `contact.html`: A contact form.

## Run the Website

Open `index.html` in a web browser and use the navigation links to visit the other pages. No additional software or libraries are required.

The shared stylesheet is located at `css/Stylesheet.css`.

## Contact Form

Choose email or mobile as the preferred contact method. The corresponding field will appear. The form does not currently send data to a server; a backend service is needed to enable submissions.
